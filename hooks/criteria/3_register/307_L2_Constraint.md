# **§ 307. L2 Constraint**

§ 307 states when an L2 language specification applies. The load path MUST follow `README.md` Section 1. The L2 text resides in the linked files in `4_L2-trigger/`.

1. HashiCorp Configuration Language
    - **(a) Applicable Scope**：The HashiCorp Configuration Language L2 specification applies when files such as `*.hcl`, `*.pkrvars.hcl`, `*.tf`, `*.tfvars`, or `*.tofu` are accessed or retrieved.
    - **(b) L2 Text**：The L2 text resides in [`hcl.md`](../4_L2-trigger/hcl.md).
2. Jupyter Notebook
    - **(a) Applicable Scope**：The Jupyter Notebook L2 specification applies when files such as `*.ipynb` are accessed or retrieved.
    - **(b) L2 Text**：The L2 text resides in [`ipynb.md`](../4_L2-trigger/ipynb.md).
3. TypeScript
    - **(a) Applicable Scope**：The TypeScript L2 specification applies when files such as `*.ts` or `*.tsx` are accessed or retrieved.
    - **(b) L2 Text**：The L2 text resides in [`typescript.md`](../4_L2-trigger/typescript.md).
4. Markdown and Prose
    - **(a) Applicable Scope**：The Markdown and Prose L2 specification applies when `*.md`, `*.mdx`, or prose files which contain a large volume of written exposition are accessed, retrieved, or generated.
    - **(b) L2 Text**：The L2 text resides in [`markdown.md`](../4_L2-trigger/markdown.md).
5. Golang
    - **(a) Applicable Scope**：The Golang L2 specification applies when files such as `*.go`, including `_test.go`, are accessed or retrieved.
    - **(b) L2 Text**：The L2 text resides in [`golang.md`](../4_L2-trigger/golang.md).
6. YAML
    - **(a) Applicable Scope**：The YAML L2 specification applies when files such as `*.yaml`, `*.yml`, or `*.j2` are accessed or retrieved.
    - **(b) L2 Text**：The L2 text resides in [`yaml.md`](../4_L2-trigger/yaml.md).
