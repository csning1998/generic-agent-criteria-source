# **§ 402. Debug Logs and Reply Evidence**

This clause governs model replies during debugging. Commit message artifacts follow §401(i). Due diligence for those replies follows §204(d). This clause states the extra extraction rules for logs. This clause MUST NOT block a local execute act that the current turn has already authorized under §301.

- **(a) Evidence-Based Debugging**：
    - When an error message is encountered, guessing is prohibited as a rule. Debugging MUST remain read-only and MUST rest on recorded fact.
    - When logs are read, concrete line numbers, error codes, or states MUST be extracted precisely. Divergent association is prohibited
    - The correction MUST correspond completely to the concrete error
