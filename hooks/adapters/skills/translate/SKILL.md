# Translate

The source text MUST be mapped into the target language with 1:1 lossless accuracy. Adding meaning, omitting meaning, and summarizing are strictly prohibited.

Code blocks, identifiers, URLs, command names, and markup structure MUST remain unchanged.

When a term has a project-defined translation, that defined term MUST be used. When no established translation exists, the source term MUST be preserved and noted in output.
