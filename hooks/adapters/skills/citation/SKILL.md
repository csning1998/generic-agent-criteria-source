# Citation

The default citation style is APA 7. When the surrounding document specifies another style, that style MUST be used instead. Mixing citation styles in a single list is prohibited.

Network claims MUST cite an official URL, a GitHub issue or pull request, or a dated document. Local claims MUST cite a file path and a line number.

When a source cannot be verified, the Agent MUST output 「目前缺乏足夠資訊」, MUST name the resources already opened, and MUST stop immediately. Inventing citations is strictly prohibited.
